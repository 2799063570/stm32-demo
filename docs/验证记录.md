## 编译与固件检查

使用Keil µVision 5.24、ARM Compiler 5.06 update 5，五个Project.uvprojx逐项完整重建，均为 **0 Error(s), 0 Warning(s)**。

`tools/check_projects.py` 检查：

- 工程文件中的路径均存在且在各自例程内，不依赖原参考资料绝对路径。
- HEX记录长度、校验和、EOF与64KiB Flash地址范围。
- 初始栈在20KiB SRAM内、8字节对齐，Reset入口为合法Thumb地址。
- SysTick及所需USART、DMA、I2C、CAN、TIM中断向量绑定到对应模块的**实际强符号**，不是启动汇编中的弱默认处理函数。
- Flash/RAM链接区地址与容量，main入口，以及构建日志中无错误/警告。

| 工程 | Flash映像跨度/字节 | RAM含栈/字节 | 结果 |
|---|---:|---:|---|
| UART+DMA+IDLE | 10096 | 2112 | PASS |
| IIC+DMA+中断 | 12296 | 1136 | PASS |
| CAN+中断 | 11520 | 1248 | PASS |
| TIM捕获+编码器 | 11516 | 1096 | PASS |
| PID+前馈闭环 | 18936 | 2264 | PASS |

Flash跨度包括初始化数据加载内容，RAM包括启动文件的1KiB栈。链接器静态调用图不能代替实际最坏栈深度与ISR耗时测量。

## 电脑端逻辑测试

通过Visual Studio C工具链，以 `/W4 /WX` 编译工程内真实PID.c、Command.c、Control.c，测试程序只用桩替代时间、编码器和电机接口。

- 完整命令、正负整数、32位边界、溢出、残缺/非法文本。
- PID输出饱和、条件积分抗饱和、前馈方向、测量微分。
- 10ms离散控制、简化一阶模型正转/反转跟踪、输出上限、零目标立即停止。
- 1000ms通信超时、故障锁定、拒绝带故障启动、CLEAR不自动启动。
- 无编码器反馈/堵转、反向反馈、串口完整性故障停机。
- 32位毫秒计数回绕前后，通信超时仍按正确时间差触发。

这些测试验证软件逻辑，不是STM32外设仿真，也不代表实际电机参数或稳定性。执行方式见根README。
