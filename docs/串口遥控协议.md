# 串口遥控协议 v2

适用于第九项STM32、C++ ROS串口桥、Python无ROS诊断工具。115200 8N1，不混入日志，多字节小端，int16补码。v2与v1不兼容，需要同时更新两端。

## 帧

A5 5A + version(uint8=2) + type(uint8) + poll_sequence(uint16) + length(uint8) + payload + crc(uint16)。最大载荷32字节，总长9+N。

CRC-16/CCITT-FALSE，多项式0x1021，初值0xFFFF，无反射/结果异或，覆盖version到payload末尾；123456789对应0x29B1。解析器支持分帧、粘帧、噪声和CRC恢复。

## POLL：类型1，载荷4字节

uint32会话。20ms轮询，单个请求在途，回复100ms截止。重新连接、超时、MCU重校准及序号回绕建立新会话/基线。

## INPUT：类型2，载荷18字节

| 载荷偏移 | 类型 | 含义 |
|---|---|---|
| 0 | uint32 | 回显会话 |
| 4、6 | uint16各1 | ADC原始X/Y，0～4095 |
| 8、10 | int16各1 | X/Y，-1000～1000，右/上正 |
| 12 | uint8 | SW按下0/1 |
| 13 | uint8 | bit0已校准、bit1 ADC有效 |
| 14 | uint8 | 页0～4：菜单、输入、三页关节 |
| 15 | uint8 | 最近命令：0无、1HOME、2ZERO、3CANCEL |
| 16 | uint16 | 最近请求编号，0无 |

未校准/ADC失效时X/Y/SW为0。命令在后续帧保留，不能逐帧重复执行；仅请求编号变化触发一次。恢复首帧仅建立基线，忽略旧请求。短按松开发HOME/ZERO，长按约0.8秒发一次CANCEL，松开不追加短按。

## FEEDBACK：类型3，载荷24字节

回显最近POLL会话/序号，STM32验证本地100ms期限。

| 载荷偏移 | 类型 | 含义 |
|---|---|---|
| 0 | uint32 | 会话 |
| 4 | uint8 | 关节来源0无、1ROS、2DEMO |
| 5 | uint8 | 六关节有效位bit0～5 |
| 6 | int16[6] | 关节角，毫弧度 |
| 18 | uint16 | 最新请求应答编号 |
| 20 | uint8 | 最新请求命令0～3 |
| 21 | uint8 | 最新请求应答状态 |
| 22 | uint8 | 当前任务状态 |
| 23 | uint8 | 当前目标0无、1HOME、2ZERO |

关节顺序shoulder_joint、upperArm_joint、foreArm_joint、wrist1_joint、wrist2_joint、wrist3_joint，按名称映射，缺失/过期/非有限值标无效。OLED显示度。

状态编号：0IDLE、1ACCEPTED、2PLANNING、3EXECUTING、4SUCCEEDED、5FAILED、6CANCELING、7CANCELED、8REJECTED、9VERIFYING、10UNKNOWN。

请求应答与当前任务分开显示；第二请求拒绝时，原任务仍可能执行。ACCEPTED来自命令节点确认；SUCCEEDED要求Action成功且实际六关节误差≤0.03rad连续保持200ms。FAILED可能表示取消未确认、仍锁定，详细原因在ROS中文message中。

## 幂等与时效

ROS服务和串口共用容量64条的会话/编号缓存。同编号同命令回放应答，不发新goal；同编号不同命令拒绝。BUSY时只允许CANCEL，取消仅针对当前goal。电脑服务不要求串口，但仍要求专用Gazebo场景。

关节和动作快照500ms过期，过期分别显示“--”和UNKNOWN；链路反馈过期显示OFFLINE。缓存旧请求在恢复连接后显示REJECT，需要重新确认。当前协议不提供认证，未实现无线或真机控制。
