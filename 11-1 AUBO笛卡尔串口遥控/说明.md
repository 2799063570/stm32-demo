# AUBO 笛卡尔串口遥控

独立的第11个Keil工程，配套你新写的 `aubo_remote_bridge/launch/cartesian_remote_gazebo.launch`。STM32F103C8T6、8MHz外部晶振、72MHz、SPL V3.5.0、ARM Compiler 5，不使用RTOS。STM32负责采样、菜单和显示；ROS侧负责逆解、速度向量归一化、控制器使能及home action。

本例程使用 `0x11 POLL / 0x12 INPUT / 0x13 FEEDBACK`，外层协议版本仍为2。**第9项固件和本仓库 `ros1/aubo_remote_bridge` 的旧HOME/ZERO桥不能替代本例程的配套电脑节点。** 应使用你提供的wheeltec_robot工作空间内的新 `cartesian_serial_bridge`。

## 接线与烧录

| 模块 | STM32引脚 | 说明 |
|---|---|---|
| 摇杆X、Y | PA0、PA1 | ADC1通道0、1，供电3.3V |
| 摇杆SW | PA2 | 自带按键：菜单短按确认；点动按住允许运动；菜单/HOME长按取消 |
| OLED CLK/D0、DIN/D1 | PB14、PB15 | 软件SPI，沿用第7～10项接线 |
| OLED CS、DC、RES | PB0、PB1、PB12 | SSD1306兼容128×64七针SPI屏 |
| USB-TTL RXD、TXD、GND | PA9、PA10、GND | USART1，115200 8N1，无流控，3.3V逻辑 |

**只需现有双轴摇杆和摇杆自带按键，不增加按钮**；PA3～PA6无需接线。SW按下接GND，内部上拉，松开为高电平。摇杆、屏幕、开发板与USB-TTL共地；保留PA13/PA14给SWD。

打开本目录 `Project.uvprojx`，F7编译；烧录 `Objects/Project.hex`，或把 `Objects/Project.bin` 烧到 `0x08000000`。BOOT0=0。链接上限为64KiB Flash、20KiB SRAM。

## 操作顺序

1. 上电松开摇杆和自带SW。32个稳定的中部样本约需160ms；未校准显示 `CENTER + RELEASE`。不要让摇杆带偏开机，否则先回中。
2. 默认进入菜单，选中 `KEEP POSITION`。上下拨动摇杆选择项目，**每次先回中，短按SW并松开确认**。左右拨动切换菜单、J1/J2、J3/J4、J5/J6、状态页。
3. 如需回初始位，先确认控制器 `DISABLED`，选择 `HOME`。等待请求 `DONE`、控制器 `DISABLED`；HOME结束不会自动使能。六轴参考home为 `[0,0,1629,0,1663,0]` mrad，仅供与关节页比较，实际目标取ROS配置。
4. 如需保持当前位置，确认 `KEEP POSITION`，不发送HOME。点动页回中短按SW返回菜单，选择 `ENABLE`。回中并松开SW，等待对应请求 `DONE` 和控制器 `ENABLED`，点动页第3行显示 `HOLD SW`。
5. 默认XY模式，**按住摇杆自带SW再拨摇杆**，左右控制X、上下控制Y。松开SW会在下次POLL清除允许运动标志，ROS端发零速度并减速；保持本次使能，可再次按住点动。持续按住超过0.8秒仍为点动，不会误触发取消。
6. 如需控制Z，先松开SW并回中，做一次全程回中的短按进入菜单，选择 `XY / Z MODE` 切换为Z，再选 `BACK TO JOG`。屏幕第1行显示 `Z`，此时按住SW、向上拨为Z+、向下拨为Z−，左右不输出方向。XY与Z分开操作，不能同时输出XYZ三轴。
7. **点动过程中偏转过的整段按住，松开只停止点动，不会进入菜单**，即使松开前已经回中也一样。进入菜单需另做一次全程回中的短按（小于0.8秒）。菜单与反馈页始终不上报方向和允许运动标志。选择 `STOP / DISABLE` 撤销使能。
8. 已完成校准并松开过SW后，在菜单/反馈页长按约0.8秒发送一次 `CANCEL`，松开不追加短按。HOME运行时保留在菜单，长按即可取消；如已切到未授权的点动页，长按同样可取消。HOME取消期间显示 `STOPPING`/`HOME STOP`；必须等最终 `CANCELED`（或竞争完成的 `DONE`）和 `DISABLED`，不能把“取消已发送”当成“已经停稳”。

长按取消与串口停止属于软件控制，不替代控制柜硬件急停。

## 菜单与显示

| 项目 | 行为 |
|---|---|
| KEEP POSITION / BACK TO JOG | 返回点动页，不发送运动请求 |
| ENABLE | 新编号请求使能；等待应答后才允许SW按住点动 |
| STOP / DISABLE | 发零、禁用并取消HOME；可抢占上一请求 |
| HOME | 只能在禁用、停稳、回中、松键时请求 |
| CANCEL HOME | 取消HOME、停止并禁用；可抢占上一请求 |
| RESET FAULT | 故障复位，不自动使能 |
| BASE / TOOL | 基坐标/工具坐标切换，只能在本地未授权时修改 |
| SET SPEED | 循环1、5、10、25、50、100mm/s，默认10mm/s |
| XY / Z MODE | 在回中、松开SW、无待完成请求时切换输入模式；下一次重新按住SW才点动 |

BASE/TOOL坐标与速度修改前先STOP；XY/Z输入模式可在回中松键、无待完成请求时切换，保留本次使能。菜单第1行显示BASE/TOOL和XY/Z，第3行显示速度。各方向分量为−1000～1000，Z也使用摇杆比例调速，PC负责限制合成速度。改安装方向、死区、默认速度可编辑 `User/JogConfig.h`。

128×64屏使用4行ASCII以适配已有字库：

- 第1行显示串口反馈在线状态、BASE/TOOL坐标系和XY/Z输入模式。
- 中间两行显示菜单、XY或Z输入、两轴角度或故障/home状态。有效关节按mrad转成角度；无效关节显示 `--`。
- 第4行每秒交替显示**控制器当前状态**与**本机最新请求编号/应答**；两者独立。`REJECT`不代表原HOME已停。`LOCKED`表示本地尚未取得运动授权，即使PC仍报告ENABLED也不能输出deadman。
- 点动页第3行如 `HOLD SW K11 V10`：`HOLD SW`表示已有本地授权；`K`后两位分别为SW原始按下状态和消抖后状态，松开为`00`、持续按住应为`11`。`V10`表示10 mm/s，完整小数速度仍可在菜单查看。详见 [按键诊断与deadman排查.md](按键诊断与deadman排查.md)。
- 断链显示 `OFFLINE / LOCKED`，不保留旧使能、旧关节为实时值。状态页 `H` 为ROS GoalStatus，255=尚无目标；`ERR` 为最近HOME反馈误差，非实时目标距离。

ENABLE/HOME/RESET需要反馈新鲜、控制器状态允许、上一请求已完成。条件不满足时本地不生成新编号；先回中松键、检查状态、等待上一请求完成，再确认。STOP/CANCEL可随时覆盖上一离散请求。

## 启动配套ROS仿真

在已经包含新入口的ROS工作空间执行：

```bash
catkin_make
source devel/setup.bash
roslaunch aubo_remote_bridge cartesian_remote_gazebo.launch port:=/dev/ttyUSB0

# 如已经启动cartesian_jog_gazebo，只附加串口桥：
roslaunch aubo_remote_bridge cartesian_serial_bridge.launch \
  port:=/dev/ttyUSB0 joint_states_topic:=/aubo_i5/joint_states

# 查看请求和控制器反馈：
rostopic echo /remote/cartesian_status
rostopic echo /cartesian_jog/state
```

STM32是被轮询端，不主动周期发送旧INPUT；只打开串口助手而没有发送POLL时，显示OFFLINE属于正常现象。运行ROS时关闭占用同一串口的助手。

## 串口助手台架调试

无ROS时按 [串口助手调试.md](串口助手调试.md) 验证。已提供可复制的HEX、原始BIN、INPUT解码和 `jog_assistant.py` 自动模拟工具。手动报文用于单次收发检查；持续看OLED和测试ENABLE/XY/Z/HOME/CANCEL时使用自动递增轮询。第11项拒绝重复序号，不能循环发送同一固定报文；全部模拟反馈不代表机械臂实际状态。

## 模块与协议来源

| 文件 | 职责 |
|---|---|
| User/main.c | 5ms采样、非阻塞UART收发、100ms屏幕更新、ADC失败每秒重试 |
| Hardware/Joystick.c、JogKeys.c | 双ADC与PA2单按键采集；所有ADC等待有超时 |
| Hardware/Serial.c | USART1循环DMA接收、HT/TC/IDLE、FIFO、DMA发送 |
| System/RemoteProtocol.c、RemoteJogProtocol.c | 与新ROS桥一致的帧解析、CRC、字段编解码 |
| System/JogRemote.c | 校准、消抖、菜单、请求编号、会话及授权状态 |
| System/JogView.c | 菜单、关节有效位、请求应答、控制器状态、故障与HOME反馈 |

协议源码来自 `D:\files\code\wheeltec_robot\wheeltec_robot\aubo\aubo_remote_bridge`，仅将C源文件中 `aubo_remote_bridge/` include前缀去除以适配平面头文件目录。完整协议文档快照见 [协议参考.md](协议参考.md)，来源和文件SHA256见 `协议来源.json`。

INPUT固定18字节，FEEDBACK固定28字节；整数显式小端编码，不发送结构体内存。新session第一帧沿用原请求编号作为基线，不自动发起旧请求；新请求编号1..65535循环。成功发送INPUT后，只接收同session、同sequence、100ms内的一份FEEDBACK。重复反馈、旧编号、旧会话不刷新在线时间。

采样超过20ms未更新、UART错误/丢字节/发送失败、反馈100ms未更新、输入/控制器状态无效时立即撤销本地授权。保持采样与POLL响应，PC按自身策略停止/禁用。恢复后必须回中松键，并重新显式使能；迟到的旧ENABLE/DONE不能恢复授权。使能应答前如输入条件改变，上报输入无效直到PC确认禁用，防止迟到的使能结果重新开放运动。
