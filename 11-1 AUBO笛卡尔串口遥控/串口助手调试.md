# 第11项：串口调试助手与台架模拟

使用现有单摇杆固件，不增加按钮，也不需要重烧调试专用固件。本程序是“PC发POLL、STM32回INPUT”的二进制协议，上电后不会主动输出文本。

先用普通串口助手验证收发与字段，再用本目录 `jog_assistant.py` 的自动模式持续验证菜单、使能、XY/Z、HOME/CANCEL及断线锁定。工具不调用ROS或机械臂；所有角度、状态和HOME完成反馈都是模拟数据。

## 1. 接线与设置

| USB-TTL | STM32 |
|---|---|
| TXD | PA10（STM32 RX） |
| RXD | PA9（STM32 TX） |
| GND | GND |

USB-TTL使用3.3V逻辑。开发板单独USB供电时转接器只接TX/RX/GND。摇杆PA0/PA1/PA2、OLED接线沿用 [说明.md](说明.md)，PA3～PA6不接按钮。

串口助手选择对应COM口，设置 **115200、8N1、无流控、HEX发送、HEX接收**。关闭自动追加CR/LF、自动CRC、本地回显和逐字节发送延时。关闭ROS或其他占用同一串口的程序。烧录本目录 `Objects/Project.hex`，复位并松开摇杆与SW，等待约160ms校准。

## 2. 首次POLL与INPUT解读

板子复位后，复制下面13字节到HEX发送框，**手动发一次**：

```text
A5 5A 02 11 01 00 04 78 56 34 12 EF 45
```

这是session=`0x12345678`、sequence=1的POLL。STM32返回27字节INPUT，开头应为：

```text
A5 5A 02 12 01 00 12 78 56 34 12 ...
```

接收数据按每个 `A5 5A` 帧头从0计数，剔除助手时间戳、方向标签和空格：

| 完整INPUT偏移 | 字段 | 观察方式 |
|---|---|---|
| 4～5 | sequence，小端 | 与本次POLL一致 |
| 7～10 | session，小端 | `78 56 34 12` |
| 11～12 | request_id，小端 | 最近一次离散请求编号；开机0 |
| 13 | command | 00无、01ENABLE、02STOP、03HOME、04CANCEL、05RESET |
| 14 | flags | bit0采样有效、bit1校准完成、bit2点动许可；常见03，已使能且点动页按住SW为07 |
| 15 | frame | 00 BASE，01 TOOL |
| 16 | 保留 | 必须00 |
| 17～18 | speed，小端 | 0.1mm/s，默认 `64 00`=10mm/s |
| 19～20 | X，int16小端 | `E8 03`=+1000，`18 FC`=−1000 |
| 21～22 | Y，int16小端 | 同上 |
| 23～24 | Z，int16小端 | Z模式用摇杆上下控制 |
| 25～26 | CRC，小端 | 改动任何字节都需重算 |

本协议不上传原始ADC、菜单页码或独立SW电平。**flags bit2表示经过授权后的点动许可，不能直接当物理SW**；在菜单中按住SW时，bit2仍为0。菜单/关节页所有方向为0。若需手动观察方向，先回中短按默认 `KEEP POSITION` 进入点动页，再偏转摇杆，发送新的POLL；即使未使能也可看到方向，但bit2为0。

第11项拒绝同session下重复或倒退的sequence。发送过sequence=1后，反复点同一行不会继续收到INPUT，这是正确行为。下一次必须发2、3、4……；65535后换新session，并重新回中、显式使能。重新打开COM口不会重置板子上的序号。

## 3. 手动模拟关节/故障反馈

同次发送POLL紧跟FEEDBACK可一次验证双向解析。下面整行共50字节（13+37），sequence=2；不要在两帧之间加入换行或延时：

```text
A5 5A 02 11 02 00 04 78 56 34 12 6D 9D A5 5A 02 13 02 00 1C 78 56 34 12 00 00 00 00 02 FF 05 3F 00 00 23 06 DD F9 46 0C BA F3 F4 01 FF FF 00 00 16 84
```

固件会回一份INPUT，并短暂接受模拟反馈：控制器DISABLED、六轴有效、角度约为0°、+90°、−90°、+180°、−180°、+28.6°。FEEDBACK自身不另回确认帧。

**单次反馈只保持约100ms，OLED刷新也为100ms，因此可能只闪一下，甚至看不到完整画面。** 不要据此判断没有收到反馈，也不要循环同一个50字节包：重复序号不会刷新超时。需要稳定显示和交互测试请直接使用第4节自动模式。

[串口助手报文](串口助手报文/)提供以下文件；按序号依次手动发送，每个只发一次：

| 文件前缀 | 内容 |
|---|---|
| 01_poll_seq1 | 13字节POLL，无反馈，OLED保持OFFLINE |
| 02_joints_seq2 | 50字节POLL+六轴模拟反馈，DISABLED |
| 03_joints_invalid_seq3 | 50字节，joint_mask=0，对应关节必须显示“--” |
| 04_fault_seq4 | 50字节，FAULT、fault=5（模拟singularity_stop），本地不能点动 |

`.hex.txt`用于复制到HEX发送框；`.bin`用于助手“发送原始二进制文件”。不要以ASCII发送文本文件，也不要把BIN再次当HEX字符转换。第9项报文类型01/02/03不能用于本例程。

## 4. 持续测试：自动轮询与模拟反馈

静态串口助手如果不支持“递增序号并重新算CRC”，就不能用固定定时发送维持本链路。使用随工程提供的自动工具即可按约20ms发送新POLL，**先收到匹配的INPUT，再回复FEEDBACK**；100ms超时换新会话。无需ROS。

在仓库根目录运行，Python 3.8或更新版本；离线生成/解码只用标准库，自动打开串口需要pyserial。本机检查时尚未安装pyserial，首次运行前安装：

```powershell
python -m pip install pyserial
# 查看USB-TTL的COM口
python -m serial.tools.list_ports

# 先关闭普通串口助手，把COM5换成你的实际端口
python ".\11-1 AUBO笛卡尔串口遥控\jog_assistant.py" run --port COM5
```

独立解压工程后，在工程目录运行 `python .\jog_assistant.py run --port COM5` 即可。自动工具和普通串口助手不能同时打开同一个COM口；需要回到助手时，先Ctrl+C退出工具。

终端始终以 `[SIM]` 标识模拟结果，显示请求ID/命令、flags、坐标系、速度、XYZ方向和模拟应答/控制器状态。OLED协议没有DEMO来源字段，**屏幕PC:OK、ENABLED、DONE都只是本次模拟反馈，不能当成ROS在线或机械臂到位**。

按下面顺序测试现有摇杆和自带SW：

1. 校准后启动工具，OLED应稳定PC:OK、DISABLED，左右翻页可看固定模拟六轴角度。
2. 回到菜单，选择 `ENABLE`，回中短按SW并松开，保持回中松键等待应答。应显示对应编号DONE，点动页出现HOLD SW。
3. 按住SW并拨动摇杆，终端XYZ跟随比例变化、flags=07；松开SW后flags回到03，模拟控制器从JOGGING回到ENABLED。
4. 点动持续按住超过0.8秒不应生成CANCEL；有偏转的一段按住，回中松开不应跳菜单。另做一次全程回中的短按才返回菜单。
5. 在菜单切换 `XY / Z MODE`，再返回点动页。按住SW上下拨动只改变Z，X/Y为0；松开仍清许可。
6. 菜单选择STOP，等待DONE/DISABLED；再选择HOME，工具模拟约2秒运行后DONE，保持DISABLED。该过程不会产生真实轨迹。
7. 再次HOME，在完成前长按SW约0.8秒；应产生新编号CANCEL，模拟反馈CANCELED/DISABLED。HOME模拟时长只是测试值，不是真实机械臂耗时。
8. 点动后Ctrl+C停止工具，约100ms撤销本地授权，下次屏幕刷新显示OFFLINE。重新运行工具后保持回中松键，不能靠旧ENABLE应答恢复点动，必须再次显式ENABLE。

HOME模拟成功时六轴样本切换成 `[0,0,1629,0,1663,0]` mrad；点动不积分更新模拟角度。这个工具用于验证串口和固件状态流，不模拟机械臂运动学、制动、碰撞或ROS服务时序；下一步仍需Gazebo联调。

## 5. 离线生成与解码

下面命令不打开串口，不需要pyserial：

```powershell
# 生成下一个POLL；sequence必须大于板子当前会话已接收的值
python ".\11-1 AUBO笛卡尔串口遥控\jog_assistant.py" frame --sequence 5
# 生成sequence=6的一次POLL+禁用控制器/六轴反馈
python ".\11-1 AUBO笛卡尔串口遥控\jog_assistant.py" frame --sequence 6 --feedback
# 按实际请求ID、命令生成匹配的模拟应答，CRC自动重算
python ".\11-1 AUBO笛卡尔串口遥控\jog_assistant.py" frame --sequence 7 --feedback --request-id 1 --command enable --ack done --controller enabled --flags 7
# 重建交付的4组固定报文文件
python ".\11-1 AUBO笛卡尔串口遥控\jog_assistant.py" examples
# 解码从助手复制的完整INPUT（替换引号内内容，去除时间戳）
python ".\11-1 AUBO笛卡尔串口遥控\jog_assistant.py" decode "A5 5A ..."
```

应答命令必须与请求ID对应；非零命令配非零ID。手改HEX字段会使CRC失效。第三条只生成模拟报文，不能越过固件的本地使能前提或100ms期限；测试完整使能流程应使用自动模式。

## 6. 排查与验证范围

| 现象 | 检查 |
|---|---|
| 完全没有INPUT | HEX模式、TX/RX交叉、共地、波特率、COM口、是否烧录第11项；复位后单发第2节POLL |
| 第一包回复，后面没回复 | 重复/倒退sequence；生成新序号，不要套用第9项循环固定报文方式 |
| 有INPUT但PC:-- | 只发POLL没有反馈，或反馈session/sequence不符/超时，这是独立于接收是否正常的在线判定 |
| PC:OK只闪一下 | 静态单次反馈100ms到期；使用自动工具持续测试 |
| flags一直03，按SW不变 | 菜单不发点动许可；先在新鲜反馈下显式ENABLE，并处于点动页 |
| X/Y/Z一直0 | 菜单/关节页方向固定0；进入点动页，检查XY/Z模式和校准 |
| ENABLE没编号或仍LOCKED | 回中松SW、控制器DISABLED、上一请求完成；使能应答前不能提前按SW |
| 打不开COM | 关闭其他串口助手/ROS；检查实际COM号和USB-TTL驱动 |
| 重新启动工具不自动点动 | 新会话清授权，这是预期行为；重新回中并显式ENABLE |

运行完整离线回归：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\test_jog_remote.ps1
```

真实C固件解析交付的BIN，检查六轴/无效位/故障和重复包超时；C生成的INPUT与Python编码逐字节比对。Python测试覆盖分包/坏CRC、会话/序号匹配、先INPUT后FEEDBACK以及模拟ENABLE、释放、HOME、CANCEL、去重与旧请求基线。**未连接实体串口或实际操作串口助手验证**，不将测试桩称为电气收发测试。
