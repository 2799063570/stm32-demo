# 2-1 IIC + DMA + 中断

## 接线

| STM32 | MPU6050模块 |
|---|---|
| PB10 / I2C2_SCL | SCL |
| PB11 / I2C2_SDA | SDA |
| 3.3 V、GND | 兼容3.3 V的VCC、GND |
| GND | AD0（7位地址0x68） |

SCL/SDA各接约4.7kΩ上拉到3.3 V，已有合适上拉的模块无需重复添加。PA9接USB-TTL RXD查看115200日志，GND共地。MPU的INT引脚本例未使用，这里的中断是STM32的I2C事件/错误和DMA中断。

## 目录与资源

`User/main.c` 发起业务，`Hardware/IIC.c` 实现状态机，`Hardware/Serial.c` 只做轮询日志。

| 资源 | 用途 |
|---|---|
| I2C2 | 100kHz，EV/ER中断 |
| DMA1_Channel4 | I2C2_TX，寄存器地址和数据一起发送 |
| DMA1_Channel5 | I2C2_RX，多字节接收 |
| USART1 | 仅日志发送，**不使用DMA** |

STM32F103的I2C2与USART1恰好会使用相同DMA通道，因此本工程不能直接再初始化第一项的DMA串口；不能将两个驱动原样合并运行。

## 状态机

```text
写：START_W → ADDR_W → TX_DMA → TX_BTF → STOPPING → IDLE
读：START_W → ADDR_W → REG_SENT → RESTART → ADDR_R → RX_DMA → STOPPING → IDLE
错误/超时：当前状态 → STOPPING → 发布错误结果
```

- EV中断处理SB、ADDR、BTF和重复起始；ERR中断处理NACK、仲裁丢失和总线错误。
- 发送DMA TC之后还要等BTF，确认最后一字节真正发完，再请求STOP。
- 接收只支持2～32字节。清接收ADDR前先配置ACK、DMA与LAST，让硬件在末字节NACK；接收DMA TC后请求STOP。
- DMA搬运期间关闭事件中断，避免BTF等事件反复触发；错误中断仍保持开启。
- `IIC_Service()` 在主循环检查50ms事务超时与最多5ms的停止等待，没有在ISR里循环等待。
- 结果只在收尾后发布一次；旧结果未消费时，新的事务返回BUSY。

## 应用示例

启动时用DMA写 `0x6B=0x01` 取消睡眠，等待100ms后，从 `0x3B` 连续读14字节，加速度、温度、角速度的原始字节都在 `MPU6050_Data[]`，示例打印AX/AY/AZ。约每100ms读一次。

```c
IIC_WriteRegsDMA(0x68, Reg, Data, Length);  // 写长度1~32，数据启动时复制
IIC_ReadRegsDMA(0x68, Reg, Data, Length);   // 读长度2~32，Data必须持续有效直到完成
IIC_Service();                            // 主循环反复调用
IIC_GetResult(&Result);                    // 1=有新结果，0=尚未完成
```

启动函数返回IIC_OK仅表示事务已提交。直到 `IIC_GetResult()` 返回新结果且Result=IIC_OK，才允许使用DMA读取的数据。

| 结果 | 含义 |
|---|---|
| 0 OK | 成功启动/最终成功，按调用接口区分 |
| 1 BUSY | 当前有事务、旧结果未消费或总线忙 |
| 2 NACK | 从机未应答 |
| 3 BUS_ERROR | 总线错误/仲裁丢失等 |
| 4 DMA_ERROR | DMA传输错误 |
| 5 TIMEOUT | 事务或STOP等待超时 |
| 6 ARGUMENT | 地址、长度或指针错误 |

## 验证与限制

正确连接后，转动模块时加速度原始值应变化；可用逻辑分析仪确认100kHz、重复START、末字节NACK和STOP。断电移除模块后再上电，应报告NACK或超时并持续运行。检查原始字节与器件手册，不把编译成功当作实际采样验证。

本驱动固定7位从机地址、8位寄存器地址，不实现单字节DMA接收、10位从机地址、16位EEPROM地址或多主机协议。发生永久BUSY时不会死循环，但仍需检查物理总线/从机，并按ST ES096处理模拟滤波器锁定问题；本例没有完整GPIO总线解锁算法。

## SPI OLED可视化更新

屏幕走独立SPI1：PB3/PB5、PB0/PB1/PB12，见 [统一OLED说明](../docs/OLED接线与显示.md)。MPU6050仍在PB10/PB11的I2C2，DMA4/5不变。显示事务结果和最新AX/AY/AZ，无有效采样时明确提示NO VALID DATA。每次主循环先处理IIC状态机，再推进一个OLED小事务。
